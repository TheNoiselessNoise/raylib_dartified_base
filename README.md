# raylib_dartified_base

Platform interface package for `raylib_dartified` package family.

This package defines the abstract API that platform implementations must fulfill.

## For platform implementors

See `raylib_dartified` (FFI) and `raylib_dartified_web` (WASM) for reference implementations.
